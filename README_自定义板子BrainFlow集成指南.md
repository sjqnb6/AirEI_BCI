### 问题分解

```
你的硬件板          电脑
   ↓                 ↓

数据        数据包            通信         解析             处理
```

### 需要做的三件事

#### 1️⃣ 数据格式标准化

**Cyton数据包格式 (33字节)**:
```
┌──────────┬────────┬──────────────────────┬──────────┬────────┐
│ 0xA0     │ Counter│ EEG (8ch × 3bytes)  │ AUX      │ 0xC0   │
│ 1 byte   │ 1 byte │ 24 bytes             │ 6 bytes  │ 1 byte │
└──────────┴────────┴──────────────────────┴──────────┴────────┘
             ↓
    包计数器递增0-255
    用于检测丢包
```

#### 2️⃣ 通信连接建立

**选择一种通信方式**:

| 方式 | 优点 | 缺点 | 适合 |
|------|------|------|------|
| **串口** | 简单、稳定 | 有线 | 开发测试 |
| **WiFi** | 无线、灵活 | 复杂度高 | 最终产品 |

#### 3️⃣ BrainFlow集成

```java
// 最少代码即可工作
BrainFlowInputParams params = new BrainFlowInputParams();
params.serial_port = "COM3";  // 改为实际端口

BoardShim board = new BoardShim(BoardIds.CYTON_BOARD, params);
board.prepare_session();
board.start_stream();

double[][] data = board.get_board_data();  // 自动解析你的数据包！
```

## 💡 关键要点记忆表

记住这些核心点，其他都可以推导：

### 1. 数据包起点和终点
```
每个包都以 0xA0 开始，以 0xC0/0xC1 结束
这是对齐和同步的关键
```

### 2. 包计数器的作用
```
package_counter++  每个包递增
0 → 1 → 2 → ... → 255 → 0 → 1 → ...

用来检测丢包:
  if (counter != (last_counter + 1) % 256) {
      packets_lost++;
  }
```

### 3. 小端序（LSB first）
```
3字节通道数据 → 24-bit整数
byte[0] = LSB (权重最小)
byte[1] = MID
byte[2] = MSB (权重最大)

例子: 0x12, 0x34, 0x56
     = 0x563412 (小端序)
```

### 4. 数据范围
```
EEG值 ≈ ±200mV (正常脑电信号)
如果看到 ±10000 mV → 字节序错了
如果看到都是 0 → 硬件没输入或格式错了
```

### 5. 通信速率
```
250 Hz × 33 bytes/packet = 8.25 KB/sec
115200 baud = 14.4 KB/sec
满足要求 ✓
```
